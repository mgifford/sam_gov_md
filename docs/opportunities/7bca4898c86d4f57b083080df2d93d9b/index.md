# Information Technology Support Services (ITSS) Bridge Contract

- Agency: COMMERCE, DEPARTMENT OF
- Type: Justification
- Posted: 2026-05-20 09:52:28.941-04
- Solicitation Number: 1332KP26F0037

## Summary

NESDIS' National Centers for Environmental Information (NCEI) requires services to support the operations and maintenance (O&M) of the NOAA5009 Federal Information Security Modernization Act (FISMA)-moderate Local Area Network (LAN); NOAA5009 is the identifier that refers to the NCEI Archive, which is one of the most significant archives on Earth, with comprehensive oceanic, atmospheric, and geophysical data. NCEI archives over 229 terabytes of data each month from over 130 observing platforms. Many organizations and businesses use NCEI's environmental data to make informed decisions about their goods and services. The services required to maintain the NOAA5009 are: operations support, configuration management, Help Desk operations, Data Center Infrastructure Management, cable management, network and security operations, Wide Area Network (WAN) and LAN support, security configuration management, continuity of operations, network and system administration, network faults management, networks account administration management, networks performance and security management, system administration and user support, system fault management, system administration performance management and security performance, database administration, IT System analysis, capacity planning, preventative maintenance on operational equipment including replacement parts modification and upgrades, obsolescence prevention and remediation, system hardware and software inventory, hardware procurement support, and software and software license procurement and maintenance support.

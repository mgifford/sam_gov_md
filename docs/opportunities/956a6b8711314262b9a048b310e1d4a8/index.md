# News Monitoring Services

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-29 15:23:25.473-04
- Solicitation Number: W91QEX26QA011

## Summary

The 410th Contracting Support Brigade (CSB), Regional Contracting Office (RCO) - Miami, in support of the US Southern Command (USSOUTHCOM) Public Affairs Office, has a requirement for a competitive Firm-Fixed-Price (FFP) Purchase Order for a base year plus four (4) 12-month option periods. This requirement is to provide a non-personal services contract to furnish all personnel, equipment, supplies, facilities, and other items necessary to perform news monitoring services using a cloud-based subscription platform. Additionally, the Contractor shall deliver an AI-enhanced, web-based interface that aggregates and analyzes broadcast news and social media content to automatically generate insights, sentiment analysis, and recommendations by processing millions of data points using natural language processing and machine learning algorithms. All interested offerors are instructed to read the Performance Work Statement (PWS) in its entirety. Please note that Amendment 0001 has been uploaded to the solicitation package to provide official responses to vendor clarifications. All prospective offerors must review this amendment and the attached clarification document prior to submitting their final quotes.

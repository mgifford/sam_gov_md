## Summary

AMENDMENT 001: Change Product Service Code from J012 to J063. Dover Air Force Base has a requirement for Fire Alarm Maintenance and Repair Services in accordance with the Performance Work Statement (PWS.) Please see Attachment 1 - Fire Alarm Maintenance & Repair PWS for a complete description of services. This is a combined synopsis/solicitation for commercial services prepared in accordance with the format in Subpart 12, as supplemented with additional information included in this notice.

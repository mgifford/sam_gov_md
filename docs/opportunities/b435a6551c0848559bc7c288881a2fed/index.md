# USNS Comfort requirement for preventative maintenance (PM), calibration and repair services for the HistoCore PELORIS 3 110V Dual Retort TP, Tissue processor

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-13 14:45:20.578-04
- Solicitation Number: N0018926QB058

## Summary

This requirement is for preventative maintenance (PM), calibration and repair services for the HistoCore PELORIS 3 110V Dual Retort TP, Tissue processor. The Contractor shall provide for all-inclusive labor, supervision, parts, diagnostic equipment, inspections, and shipping, necessary for calibration and any required corrective maintenance for all equipment identified above. The Contactor shall maintenance the Laboratory analyzer within the original equipment manufacturer (OEM) specifications, in like new or better condition

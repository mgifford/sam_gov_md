## Summary

Intent to Sole Source – 6BDE JCLC Black Creek Requirement Number: PANMCC26P0000043217 Description: This is an Intent to Sole Source. This is NOT a solicitation for proposals, proposal abstracts, or quotations. The purpose of this notice is to provide information regarding this requirement.

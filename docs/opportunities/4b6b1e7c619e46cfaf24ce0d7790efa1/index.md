# Notice of Intent to Award Sole Source - Gerber Software

- Agency: DEPT OF DEFENSE
- Type: Special Notice
- Posted: 2026-05-13 15:00:31.093-04
- Solicitation Number: F4FDAL6133A001

## Summary

The Department of the Airforce intends to award a sole source effort to Gerber Technology to aqcuire software for pattern grading systems used for design of Air Force uniforms. Based on market research, only one source will satisfy the Government's requirement. The authority for this action is RFO 13.101(b), which permits soliciting from a single source if the Contracting Officer determines that the circumstances of the contract action deem only one source reasonably available.

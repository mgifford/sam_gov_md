## Summary

Amendment 0001- Solicitation W911S626QA006 Motorola Communication System Upgrade Description: The purpose of Amendment 0001 to Solicitation W911S626QA006 is to add redacted J&A for Brand Name Motorola to Solicitation file. ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- Dugway Proving Grounds (DPG) Security Guard Branch requires upgrade, replacement, and configuration of outdated Motorola-based communication system (Radios and Accessories). The contractor shall provide all labor, materials, equipment to meet the install and setup requirements. The scope includes the procurement and delivery of Motorola equipment, installation in facilities and vehicles, system programming, testing, removal of obsolete hardware, and basic user training.

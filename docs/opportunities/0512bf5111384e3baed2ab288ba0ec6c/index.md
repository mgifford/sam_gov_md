# 6" Wet Pump Clutch Osh Kosh Stryker Fire Truck

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-05 15:51:47.335-04
- Solicitation Number: W50S6N26QA016

## Summary

The 187th Vehicle Management requires repair on an Oshkosh Striker fire truck 06L00344 VIN 10TBKAK176S085734. Right now, the vehicle is inoperable. It will not go into pump mode. The repairs are for the 6” Wet Clutch Pump Drive replacement. These repairs are needed so that this fire truck can become operational to support the 187th Flying mission and the Montgomery Regional AirporT. For a detailed description of the required repair please refer to the attached PWS.

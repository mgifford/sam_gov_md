# Pipe Bending Machine Parts

- Agency: DEPT OF DEFENSE
- Type: Special Notice
- Posted: 2026-05-15 14:52:19.768-04

## Summary

The Naval Supply (NAVSUP) Systems Command, Fleet Logistics Center Jacksonville (FLCJ), FL intends to issue a sole source award utilizing simplified acquisition procedures Jesse Engineering Co. for Pipe Bending Machine Parts. See DRAFT DOR attached. The applicable North American Industrial Classification System Code (NAICS) code is 332996, with a size standard of 550 Employees. This notice of intent is for informational purposes only. This notice does not constitute a request for proposals, request for quote or an invitation to bid. All sources eligible to provide the requirement must respond in writing. Responses must be supported with clear and convincing evidence to clearly articulate the ability to provide the requirement as outlined above. Must provide written proof if you are a distributor of Jesse Engineering Co. A request for documentation will not be considered as an affirmative response. If no response is received to this notice by 30 May 2026 at 10:00 A.M. ET, to the effect that comparable items are available, and that this is more advantageous to the Government than obtaining this product though a sole source contract, then a sole source acquisition award will be made. Response to this notice shall be sent to Laura.a.martinez10.civ@us.navy.mil and kyle.a.nelson2.civ@us.navy.mil

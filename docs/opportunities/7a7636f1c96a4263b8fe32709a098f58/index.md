# Crash Investigation Sampling System (CISS) – Primary Sampling Units (PSU) Operations Center

- Agency: TRANSPORTATION, DEPARTMENT OF
- Type: Presolicitation
- Posted: 2026-04-30 14:27:18.206-04
- Solicitation Number: 693JJ926R000032

## Summary

The objective of this contract is to provide support for the for the PSU Operations Center (PSUOC) for NHTSA’s Crash Investigation Sampling System (CISS). This includes operational oversight of personnel at the seventy-three (73) CISS PSUs, administrative management of work locations, and execution of the standardized crash data collection activities using CISS Data Systems. The seventy-three (73) PSUs include sixty-five (65) currently operational and eight (8) additional units anticipated to be added in 2027.

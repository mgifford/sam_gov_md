# Brand Name DAQ StarWatch SMS System SOF TEMF

- Agency: DEPT OF DEFENSE
- Type: Special Notice
- Posted: 2026-05-28 18:18:36.094-04

## Summary

Description SPECIAL NOTICE: The U.S. Army Corps of Engineers (USACE) intends to issue a solicitation for the procurement and installation of an Intrusion Detection System (IDS) using a brand name or equal description for the ”DAQ StarWatch Security Management System (SMS) Software” and compatible hardware. As part of the upcoming construction solicitation, USACE intends to include the following brand name requirement: ”DAQ StarWatch Short Message Service (SMS) software system.” Justification: this requirement is essential for the existing, installation-wide proprietary DAQ StarWatch Security Management System (SMS). The new Intrusion Detection System (IDS) must be 100% compatible with and natively communicate with the existing DAQ StarWatch Command and Control (C2) head-end servers to ensure the operational integrity of the installation's security posture and meet the requirements of UFC 4-021-02, Electronic Security Systems.” Standardization is necessary to ensure compatibility with existing equipment, software, and service contracts. Utilizing a different system would require adaptive software or additional equipment, leading to substantial duplication of costs for installation, training, and reprogramming, which are not expected to be recovered through competition. Disclaimer: This is NOT a solicitation or a request for competitive proposals. The purpose of this notice is to inform industry of the Government's intent. All responsible sources may identify their interest and capability to respond to this requirement. The Government will consider all capability statements received by the response date solely for the purpose of determining whether to conduct a competitive procurement. A determination by the Government not to compete this proposed action based upon responses to this notice is solely within the discretion of the Government. All information furnished must be in writing and must contain sufficient detail to allow USACE to determine if the interested party can perform the requirement described herein. Compatible system(s) must comply with Revolutionary FAR Overhaul (RFO) Provision 52.225-12, Notice of Buy American Requirement-Construction Materials Under Trade Agreements, and Federal Acquisition Regulation (FAR) Clause 52.225-11, Buy American-Construction Materials under Trade Agreements. All responsible sources may submit a capability statement, which shall be considered by the agency. The submission must be received no later than 10:00 AM PT on Jun 12 2026, to linda.s.obrien@usace.army.mil

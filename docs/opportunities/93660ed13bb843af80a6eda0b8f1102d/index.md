## Summary

Travis AFB CA has a requirement for Aircraft Regulated Garbage Services (Pick-Up & Disposal). This is for a potential 5-year contract. See Performance Work Statement (PWS) for a full detail of the requirement. The Request for Information (RFI) Sources Sought does not constitute a Request for Quote (RFQ) or a promise to issue a future RFQ. This sources Sought does not commit the Government to contract for any supply or service. Further, the Air Force is not currently seeking proposal and will not accept unsolicited proposals. Not responding to the RFI, does not preclude participation in any further RFQ, if issued.

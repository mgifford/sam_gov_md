## Summary

PBGC requires support from Gigamon network packet broker systems. Components of the current Gigamon systems A network packet broker is a purpose-built monitoring infrastructure technology which is installed between PBGC network infrastructure and its security and management tools. Packet brokers allow implementation of a wide range of network tools to access, monitor and analyze network traffic across the enterprise. PBGC presently uses Gigamon network packet broker systems.

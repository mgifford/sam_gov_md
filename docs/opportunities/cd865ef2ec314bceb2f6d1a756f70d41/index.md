# Maxwell 42CS Virtual Core Server Sustainment (Warranty)

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-04 14:13:56.254-04
- Solicitation Number: MAX-RFI42CS0526

## Summary

The 42nd Communications Squadron at Maxwell AFB, AL has a requirement for Warranty and Sustainment Support for its SIPR/NIPR Virtual Core Server Equipment which is approaching the end of the manufacturer's original warranty period for support. The equipment provides the SIPR/NIPR Virtual Environment for Core Services (File, Print, & Web) for restoration after local Tier I through Tier III efforts have been documented. Please be aware that this is just a Request for Information and no contract will result from this inquiry. Please see the attached Sources Sought and draft SOR for all information regarding this requirement and how to submit a capabilities statement.

# Nitrogen Generator

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-04-30 12:15:49.812-04
- Solicitation Number: W911S226U3136

## Summary

Nitrogen gas generator. Provides up to 35 LPM of nitrogen using room air, variable to 116 PSI. Produces 99.5% pure nitrogen. Uses a touchscreen user interface with integrated compressor. Comes with 1 year manufacturers warranty. Comes ready for AC 120V outlet and comes with 3-prong plug.

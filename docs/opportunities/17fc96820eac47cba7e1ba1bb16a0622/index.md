# Small Delivery Unit Sorter (SDUS) FY26 Program

- Agency: POSTAL SERVICE
- Type: Award Notice
- Posted: 2026-04-29 13:37:23.195-04
- Solicitation Number: 3APCKG-25-B-0006-MOD15
- Awardee: INTRALOX LLC New Orleans LA 70123 USA
- Award Amount: 38867235.00

## Summary

Intralox LLC has been awarded a non-competitive contract modification for the Small Delivery Unit Sorter (SDUS) FY26 Program. The SDUS is a package sorting system that is being deployed to small Delivery Units within the U.S. Postal Service network. The value of the contract modification is $38,867,235 and includes the deployment, installation, and testing of thirty-six (36) SDUS units.

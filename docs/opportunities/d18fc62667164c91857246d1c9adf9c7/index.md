## Summary

This is a combined synopsis/solicitation for commercial products prepared in accordance with the format in FAR Part 12. This announcement constitutes the only solicitation. Quotations are being requested and a separate written solicitation will not be issued. Solicitation number 1232SA26Q0676 is issued as a Request for Quotation (RFQ) for an Automated Slide Scanner.

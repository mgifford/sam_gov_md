- Agency: GENERAL SERVICES ADMINISTRATION
- Type: Justification
- Posted: 2026-05-29 14:46:19.68-04
- Solicitation Number: 4700-P71

## Summary

This Sole Source Justification (SSJ) supports the Government’s exercise of FAR 52.217- 8, Option to Extend Services, under the current Task Order to ensure uninterrupted delivery of mission-critical IT operations across GSA. This extension provides the Government sufficient time to complete the competitive recompete acquisition, which is currently scheduled for award in the first quarter of FY27

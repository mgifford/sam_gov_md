# Request for Information LCAC Alarm and Monitoring System

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-01 12:46:12.631-04
- Solicitation Number: N61331-26-SN-Q29

## Summary

The Naval Surface Warfare Center, Panama City Division (NSWCPCD) is conducting a survey of potential sources for the Ship to Shore Connector (SSC) program. NSWCPCD is seeking sources for a commercial off-the-shelf (COTS) Alarm and Announcing System for a system upgrade effort. This is a REQUEST FOR INFORMATION (RFI) for an Alarm and Announcing System for the Ship to Shore Connector (SSC). THIS IS NOT A REQUEST FOR PROPOSALS. Please see the attachment for more information.

# Intent to Increase ceiling for FDA IDIQ CONTRACT 75F40124D00020 by $50,000,000.00 from $99,880,020.00 to $149,880,020.00

- Agency: HEALTH AND HUMAN SERVICES, DEPARTMENT OF
- Type: Special Notice
- Posted: 2026-04-28 15:55:36.138-04
- Solicitation Number: INTENTCEILINGFDA50MILL00020

## Summary

The purpose of this posting is to provide notice of the Government intent to increase the ceiling value on Contract 75F40124D00020 by $50,000,000.00 from $99,880,020.00 to $149,880,020.00. The awardee on this contract is Vets Synergetic Group LLC. This is a sole source modification action to increase the ceiling value of the contract to allow additional orders to be issued prior to the end of the contract which is June 9, 2028. The increase is required due to the following: This contract will now be utilized for Sentinel 3.0 tier 8 requirement. There is an increase in the utilization of this contract for new scientific support requirements. The contemplated modification will not change the existing contract scope, nature of work, or any other terms and conditions. All work will continue to be executed via task orders in accordance with current contract terms. This notice is published for informational purposes only and is not a request for proposals or capability statements.

# Rynglok Tool Kit

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-04-27 11:50:11.315-04
- Solicitation Number: FA301626Q0081

## Summary

The 12th Maintenance Squadron's Fabrication Flight (12MXS/MXMF) at Joint Base San Antonio-Randolph requires the immediate procurement of one (1) new RYNGLOK TOOL KIT, Part Number RTSK8-02-001 (NSN 5180-01-378-8873). This toolkit is essential for the installation and maintenance of Rynglok hydraulic tubing couplings on the T-7 RedHawk aircraft. It must include all necessary tools to service the following tubing sizes: #3 (3/16"), #4 (1/4"), #5 (5/16"), #6 (3/8"), #8 (1/2"), #10 (5/8"), #12 (3/4"), #14 (7/8"), #16 (1"), #20 (1 1/4"), and #24 (1 1/2"). As Eaton is the Original Equipment Manufacturer (OEM) with exclusive rights to the drawings, specifications, and manufacturing data for Rynglok systems, NO OTHER BRAND OF TOOL KIT CAN BE SUBSTITUTED. This action is for a new order, and the requirement will be solicited as a competitive small business purchase. The order type is a Firm-Fixed-Price (FFP) Purchase Order. The basis of award will be using the Lowest Price Technically Acceptable (LPTA) methodology.

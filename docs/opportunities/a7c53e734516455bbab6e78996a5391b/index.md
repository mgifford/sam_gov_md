Solicitation number 31140PR260000016 is issued as a request for quotation (RFQ) for Portable Toilet Units and Pump Service for USCG Base Kodiak. The NAICS Code is 562991. USCG Base Kodiak, Kodiak, AK, has a requirement for the Portable Toilet Units and Pump Service in accordance with the attached Statement of Work (SOW).

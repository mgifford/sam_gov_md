# Mobile Tower Antenna Replacement

- Agency: JUSTICE, DEPARTMENT OF
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-19 12:34:26.474-04
- Solicitation Number: PR-26-000408

## Summary

The FBI Procurement Section is issuing this RFQ and SOW for the purpose of entering into a contract for commercial services for the removal of an existing 4-dipole array antenna and installation of a Government-furnished SD214-SF2P2SNM 4-element antenna at the 1,100-foot mark of the WKRG tower (MO-043). The Contractor must advise via a timeline what they expect the period of performance for this requirement to consist of after receipt of an order. The NAICS code for this requirement is 237130, Power and Communication Line and Related Structure Construction. The Business size standard is $45 million dollars. This requirement is set aside for small businesses. Contractors interested in responding may participate by submitting a quote in accordance with the procedures set forth in this RFQ

## Summary

This is a combined synopsis/solicitation for commercial items prepared in accordance with the format in Federal Acquisition Regulation (FAR) Subpart 12.6, as supplemented with additional information included in this notice. This announcement constitutes the only solicitation; quotes are being requested in response to this notice and a written solicitation will NOT be issued. This solicitation is being issued as a Request for Quote (RFQ)# 246-26-Q-0017. Submit only written quotes for. This solicitation is a 100% BUY INDIAN SET-ASIDE. The associated NAICS code is 811210. The following factors shall be used to evaluate offers: Lowest Price Technically Acceptable The following factors shall be used to evaluate quotes: 1) Pricing 2) Technical Pricing – The government will add all items for a cumulative total.

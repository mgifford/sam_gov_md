# Renovate RM106 For Emergency Operations Center, B730

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-27 11:09:32.006-04
- Solicitation Number: EEPZ255862

## Summary

The Contractor must provide all plant, labor, equipment, transportation, and tools required to complete a full renovation of the existing alternate Emergency Operation Center (EOC). This includes performing analysis on security aspects of the alternate EOC and bringing it up to meet the UFC and AFI requirements. The main focus of this project is the installation of a separate HVAC system for the EOC and backup generator that is sized and serves the EOC, HVAC for the EOC, communication equipment serving the EOC, and the lights for nearby bathrooms. Perform all work according to this Statement of Work (SOW), all related AF requirements, and other codes and references. This is a sources sought. No award will be made off this posting. This is for market research purposes only. Please review attached SOW for further project details.

## Summary

This project will install three (3) Heating, Ventilation, Air-Conditioning (HVAC) units. Work will include integration with portions of the existing ductwork system, installation of electrical disconnects, refrigerant lines, controls, and commissioning of equipment at the historical Ebenezer Baptist Church Martin Luther Kings, Jr. National Historic Park Atlanta, Georgia.

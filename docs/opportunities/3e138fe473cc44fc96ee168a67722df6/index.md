# Premise Wiring B704

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-12 22:16:05.014-04
- Solicitation Number: FA302226Q0319

## Summary

Columbus AFB has a requirement for the Contractor to engineer, furnish, install, and test (EFI&T) the upgrade of premise wiring infrastructure to Cat-6 for the building 704 (B704) at Columbus AFB, MS. The Contractor shall install approximately 37 cable/jacks (15 duplex, 1 quad, 3 wall drop) and coordinate with the 14th CS/SCXP to verify the exact drop locations. Install & terminate [66blk, 24p PP] 25pr./24ga. riser cable. See SCXP POC for location.

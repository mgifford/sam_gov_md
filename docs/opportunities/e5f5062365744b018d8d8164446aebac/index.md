# HGU-98/P Flight Deck Cranial

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-26 14:47:04.404-04
- Solicitation Number: N0042126CPM2020293

## Summary

PMA-202 is seeking qualified business sources capable of manufacturing or supplying the following equipment: Helmet, Flight Deck, Cranial, HGU-98/P: EXFIL LTP Helmet Rail 3.0 , Size M/L P/N: 72-R3-PG-1S Green 700 Each EXFIL LTP Helmet Rail 3.0, Size: Size 2 X/L P/N: 72-R3-PG-2S Green 350 Each Quick Release Adapter Back Plate set for hearing protection P/N: 80-CAK-BP 1400 Each This helmet will provide maximum impact protection and hearing attenuation for personnel operating on aircraft carrier flight decks, flight lines, and similar hazardous high-noise environments. It must include high-impact resistant outer shell, sound-attenuating earcups, suspension/liner system, chin strap, and capability for communication system integration (e.g., lip-light, boom mic). They shall manufacture in strict accordance with the current NAVAIR technical data package (TDP) and military specifications for the HGU-98/P configuration.

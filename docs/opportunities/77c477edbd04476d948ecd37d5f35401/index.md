# Access Control System

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-13 08:45:55.725-04
- Solicitation Number: FA810126Q0004

## Summary

The 72d Air Base Wing (72 ABW) at Tinker AFB intends to establish multiple Blanket Purchase Agreements (BPAs) for the acquisition of Avigilon Brand Name access control equipment, components, and associated software. This acquisition utilizes FAR Part 12 Commercial procedures. Evaluation will be based on Lowest Price Technically Acceptable (LPTA). The Government anticipates awarding three (3) to five (5) BPAs. Instructions: This is a Brand Name only requirement (Justification attached). Interested vendors must review the attached Request for Quotation (RFQ) package for the complete BPA Schedule, Statement of Need, and all terms and conditions. Quotes must conform to all solicitation requirements to be considered. Please refer to the attached documents for full details, submission instructions, and required clauses. Attachments: Solicitation FA810126Q0004 Brand Name Justification Redacted BPA Schedule Performance Work Statement

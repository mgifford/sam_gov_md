# Request for Interest - Camp Casey Korea

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-04-29 13:40:11.808-04
- Solicitation Number: 7016498204

## Summary

This is a request for interest for a potential requirement for various food service equipment, delivery, and installation for Camp Casey Korea. This is not an active solicitation. If a solicitaiton is made later, all equipment, delivery, and installation requirements would need to be met to be eligible for award. Examples of the various equipment that would need to be provided are as follows: Tilting Skillet Braising Pans, Hot Food Serving Counters, Cold Food Serving Counters, Electric Ranges, and Pass-Thru Heated Cabinets.

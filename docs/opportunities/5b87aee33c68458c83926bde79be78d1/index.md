## Summary

This action will result in a five (5) year Firm-Fixed-Price (FFP) Indefinite Delivery Indefinite Quantity (IDIQ) contract for upgrade and overhaul of the landing gear fixed pursuant to FAR 52.216-22 using Sealed Bidding procedure under FAR Part 14. This is a 100% Small Business Set Aside. The applicable North American Industry Classification Systems (NAICS) code for this effort is 336413 and the size standard is 1,250 employees. Only bidders with NAICS code 336413 registered in Sam.gov are eligible to submit a bid. If a bidder that is not registered as a small business under NAICS Code 336413 submits a bid, the bid will be deemed non-responsive and shall not be considered for award.

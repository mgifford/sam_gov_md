# NICEinContact Software Licenses

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-20 10:50:08.281-04
- Solicitation Number: N0018926QD106

## Summary

This requirement is for 41 software-as-a-service (SaaS) platform provider licenses by NICE inContact. NICE inContact is a cloud-based contact center software platform used to manage customer interactions across voice, email, chat, and social media. Navy Recruiting Command (NRC) utilizes this service to assist chat agents with responses to inquiries from civilians who are looking for information about joining the Navy, quickly, easily and accurately.

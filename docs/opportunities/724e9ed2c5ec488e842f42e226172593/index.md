# Travis AFB, CA - DeCa Commissary Roof Replacement

- Agency: DEPT OF DEFENSE

- Posted: 2026-05-21 10:28:33.476-04
- Solicitation Number: GNFR-FC-TRA-26-26408

## Summary

Solicitation Number: GNFR-FC TRA-26-26408 Travis AFB, CA - DeCa Commissary Roof Replacement Project Number 3784-25-000008 This project will remove and lawfully dispose of or provide for recycling the existing single ply membrane, and flashings, exposing the existing polyisocyanurate insulation at the low-sloped roofs. Install designated insulation and cover board over the existing insulation and decks scheduled to remain. Replace discovered damaged decking that is scheduled to remain, repair metal deck at abandoned equipment locations. Install specified insulation, cover board and new roof membrane. Install a new, white, 90-mil, Class “A”, EPDM single ply roof system. The roof system shall be installed per manufacturer’s requirements and specifications and will qualify for the roof system manufacturer’s installation certificate. Install protective surfacing for roof traffic. The roof system shall be constructed of specified manufacturer’s materials, to meet uplift resistance.

# FY26 PIV CARD READER SYSTEM UPGRADE

- Agency: TRANSPORTATION, DEPARTMENT OF
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-26 10:26:54.139-04
- Solicitation Number: 693C7326Q000012

## Summary

***THIS SOLICITATION IS PREPARED IN ACCORDANCE WITH FEDERAL ACQUISITION REGULATION 12.201-1, SIMPLIFIED PROCEDURES.*** NOTICE OF INTENT TO SOLE SOURCE. THE EASTERN FEDERAL LANDS HIGHWAY DIVISION (EFLHD), OF THE FEDERAL HIGHWAY ADMINISTRATION (FHWA), INTENDS TO PROCURE FROM WYCLIFFE TECHNOLOGIES A PROPRIETARY SOFTWARE UPGRADE TO THE EXISTING PIV CARD READER SYSTEM WITH THE CURRENT GALLAGHER SECURITY MANAGEMENT SOFTWARE. THIS SOFTWARE UPGRADE IS IMPERATIVE AND NECESSARY FOR A MULTI-STEP UPGRADE THROUGH THE REQUIRED INTERIM VERSIONS ALLOWING EMPLOYEES TO MAINTAIN RELIABLE AND SECURE ACCESS CONTROL. WYCLIFFE TECHNOLOGIES IS THE ORIGINAL AND AUTHORIZED PROVIDER RESPONSIBLE FOR THE GALLAGHER SECURITY MANAGEMENT SYSTEM AND IS PROPRIETARY WITH STAGED UPGRADES. ALL RESPONSIBLE SOURCES MAY SUBMIT A QUOTATION WITHIN 10 DAYS FOR CONSIDERATION BY THE AGENCY, IF TIMELY.

# Mobile Storage and Installation

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-30 11:14:31.218-04
- Solicitation Number: W50S7ZQM003

## Summary

The contractor shall furnish, deliver, and install a complete warehouse storage system at Hammond ANGS, Building 3. The system shall include 32 mobile storage units and 4 relocatable storage units, with all labor, materials, equipment, tools, transportation, installation, testing, cleanup, and warranty required to provide a complete and usable system. The purpose of this requirement is to upgrade the 236 CBCS warehouse storage capability with rolling/mobile shelving and relocatable storage units to support Unit Type Code (UTC) deployable equipment and mission storage requirements.

# Software for the conversion of CGM to Vector

- Agency: DEPT OF DEFENSE
- Type: Special Notice
- Posted: 2026-04-27 13:48:39.129-04
- Solicitation Number: N6449826PD310075

## Summary

The Naval Surface Warfare Center Philadelphia has a requirement for software for the conversion of CGM to Vector (command line version) for Windows or Linux, as well as maintenance and support for that software for 3 years, this will be fulfilled on a Sole Source basis from Larson Software Technology. The proposed contract action is for supplies or services for which the Government intends to solicit and negotiate with only one source under authority of 41 U.S.C. 1901. Any questions regarding this notice should be emailed to: jillian.randazzo.civ@us.navy.mil No phone calls will be accepted.

# Request For Information (RFI) for Application, Database & Server Support Services (ADBSSS)

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-11 16:37:05.278-04
- Solicitation Number: RFI-ADBSSS-2026-01

## Summary

Please see attachment for additional info. PLEASE NOTE: THIS IS NOT A REQUEST FOR PROPOSAL (RFP). This is a Request for Information (RFI) issued solely for information and market research planning purposes, as defined in Federal Acquisition Regulation (FAR) 15.201(e). Companies should not submit proposal-style documents or that level of detail in response to this RFI. The 72d Air Base Wing Communications Directorate (SC) at Tinker Air Force Base (TAFB) is seeking to identify sources capable of providing comprehensive Application, Database, and Server Support Services. The primary goal is to acquire non-personal services for base-wide application development and sustainment; database administration; file, print, and application server administration; and quality assurance. All services will be provided on site at Tinker AFB, OK. The purpose of this RFI is to gain industry insight into current market capabilities and innovative approaches for providing Information Technology (IT) services to TAFB. The information gathered will be used to refine the Government's acquisition strategy in terms of cost, schedule, and performance.

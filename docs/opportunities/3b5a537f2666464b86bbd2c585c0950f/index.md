# Program Manager Wargaming Capabilities - Software

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-04-27 13:44:34.421-04
- Solicitation Number: M6785426I2600

## Summary

**Updated to add vendor registration information for conference on 12/3/2025** The U.S. Marine Corps (USMC) Program Manager Wargaming Capability (PM WGC) is responsible for developing and fielding an advanced suite of software tools and simulations to the General Robert B. Neller Center for Wargaming and Analysis in Quantico, VA. The intended use cases for the software include Concept Development, Capability Development, and Operational Plan Assessment. The wargames considered are comprehensive across all levels of war (Strategic, Operational, Tactical), all warfighting domains (Land, Air, Sea, Space, Cyber), and all warfighting functions (Maneuver, Fires, Intel, Force Protection, Logistics, Command and Control, Information). The collective software requirements are applicable to all levels of war, with commensurate adjustments to the resolution of models and associated metrics. PM WGC is seeking software solutions that leverage an incremental and agile approach to developing a wargaming software capability. The initial capability sought is a wargaming system capable of running the end-to-end wargaming workflow (plan, design, execute, capture data, analyze, report) in a secure Azure cloud environment. The emphasis is on providing all the required end-to-end functions for the wargaming software with as much simulation domain technical depth as possible across warfighting domains, levels of war, and warfighting functions. It must be built with a modular, open architecture to support future agile and incremental expansion and enhancement to build out the missing capabilities of the initial product.

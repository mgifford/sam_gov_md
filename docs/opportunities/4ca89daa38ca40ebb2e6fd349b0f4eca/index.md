# Multifunction Reference Thermometer

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-04-28 13:53:08.158-04
- Solicitation Number: PANRSA-26-P-0000-033708

## Summary

The U.S. Army TMDE Activity (USATA) has a requirement to implement a brand name purchase of one (1) Multifunction Reference Thermometer Readout w/Temperature model or equivalent that will be a suitable replacement for the Hart Black Stack (20+years old) for Temperature Calibrations in comparison to Type-S thermocouples. This unit has a wide range of additional functions that will allow further use throughout the Temperature Laboratory. The ADT286-TS-PKG-110V Thermometer Readout w/Temperature shall include the following specifications or equivalent (if not brand name):

1.0 Requirements: • Additel ADT286-TS-PKG—110V, Multifunction Reference Thermometer Qty: 1 Temperature Scanner Module 110 Voltage

2.0 Delivery Requirements Shipping Address: U.S. Army TMDE Activity, Attn: Matthew Watts, Building 5435, Redstone Arsenal, AL 35898

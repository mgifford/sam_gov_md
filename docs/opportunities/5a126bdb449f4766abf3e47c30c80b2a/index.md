# Brand Name Sole Source General Dynamics Mission System URC-300

- Posted: 2026-05-05 12:01:27.587-04

## Summary

This is a combined synopsis/solicitation for commercial items prepared in accordance with the format in Federal Acquisition Regulation (FAR) subpart 12.6, “Streamlined Procedures for Evaluation and Solicitation for Commercial Products and Commercial Services,” as supplemented with additional information included in this notice. This announcement constitutes the only solicitation; “quotations” are being requested, and a written solicitation document will not be issued. The solicitation number N00244-26-Q-0025 is being issued as a Request for Quote (RFQ). RFQ N00244-26-Q-0025 shall be used to reference any written quote provided under this solicitation. The solicitation document and incorporated provisions and clauses are those in effect through Federal Acquisition Circular (FAC) 2026-01 published in the Federal Register on March 13, 2026. The clauses may be accessed in full text at these addresses: https://www.acquisition.gov. This is a 100% Small Business Set-Aside Brand Name competition requirement for General Dynamics Mission System (GDMS) URC-300 system components. The North American Industry Classification System (NAICS) code for this project is 334220 with a size standard of $15 (millions of dollars).

## Summary

This is a combined synopsis/solicitation for commercial items prepared in accordance with the format in Subpart 12.2, as supplemented with additional information included in this notice. This solicitation document and incorporated provisions and clauses are those in effect through:Federal Acquisition Circular 2026-03 Defense Federal Acquisition Regulation Public Notice 2026-02 This acquisition is set aside for 100% small businesses. Requirement Information The North American Industry Size Classification System (NAICS) code associated with this requirement is 337127. The Small Business Size Standard associated with this NAICS is 500 employees. Questions must be email to the contract specialist and contacting officer by Thursday, 30 April 2026 at 2:30PM EDT. Description: 316 WG/PA provides no-fail media escort to POTUS /VPOTUS, DV, and Foreign Heads of State movements. For any movements with more than 10 media members, US Secret Service requires media to be cordoned off in a location further from the DV. This requires press risers so press is able to see above the crowd and record the movement. See attached RFQ and attachments for further details.

## Summary

This is a combined synopsis/solicitation for commercial items prepared in accordance with the format in FAR Part 12. This announcement constitutes the only solicitation. Quotations are being requested and a separate written solicitation will not be issued. Solicitation number 1232SA26Q0224 is issued as a Request for Quotation (RFQ) for roof and unit heater replacement. The applicable North American Industry Classification Standard Code is 238160 The small business size standard is $19.0M This acquisition is set-aside for Service-Disabled Veteran-Owned Small Businesses (SDVOSB). All responsible sources may submit a quotation which will be considered by the agency. The magnitude of construction is between $500,000 and $1,000,000.

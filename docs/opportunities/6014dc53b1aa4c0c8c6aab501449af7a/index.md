# Z1DA--Install ID Concrete Pad Project 593-26-104 VAMC Las Vegas, NV

- Agency: VETERANS AFFAIRS, DEPARTMENT OF
- Type: Solicitation
- Posted: 2026-05-28 12:58:14.058-04
- Solicitation Number: 36C26126R0054

## Summary

SOLICITATION-DESCRIPTION This project will install a 90’ x 61’ 4” concrete slab to support two (2) 30’ x 40’ (ea 1200 SF) storage for Interior Design (ID). The slab will include required utility runs and grounding to support the storage units. The storage will be a conditioned tuff shed (or similar type structure) with underground electrical connection, a personnel single door, and aluminum roll up door. The work will be accomplished at the VA Southern Nevada Healthcare System (VASNHS) campus located at 6900 North Pecos Road, North Las Vegas, NV 89086. (END OF SOLICITATION DESCRIPTION)

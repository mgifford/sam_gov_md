## Summary

This is a notice that a solicitation is anticipated to be forthcoming and will have all the necessary documents. Please see the attached Scope of Work (SOW) PR-2026-0214 for detailed project requirements. IAW FAR 36.204(d), the magnitude of this project is between $100,000.00 and $500,000.00. Performance and Payment Bonds are required. The scope of this project is to seal an approximately 380ft deep, disused water well. The Contractor is required to employ the necessary equipment, instruments, and materials to accomplish eh task of sealing this old well in accordance with Illinois Administrative Code Title 77 Chapter I Section 920.120. The Contractor shall complete the necessary reporting to the County of Rock Island Public Health Department including paying fees. 27 APR 2026: SITE VISIT HAS BEEN CANCELLED

## Summary

This was a sole-source justification for an award to Lockheed Martin Missiles and Fire Control (LMMFC). LMMFC is the only source with the technical knowledge, technical expertise, production infrastructure facilities, and access to the full technical data package (TDP) to produce and maintain the PAC-3 missiles.

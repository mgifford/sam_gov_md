# RFI for Main Control Center Upgrade Supplies (Wright Line)

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-19 14:19:43.461-04
- Solicitation Number: 20260004308

## Summary

This is a Request for Information (RFI)/Sources Sought. Not a solicitation. Military Correctional Facility Miramar has a Brand Name requirement for the items listed in the Statement of Work (SOW). This will enable the Main Control Center operators to maintain constant situational awareness and uninterrupted operational oversight by providing a modernized, ergonomic, and technologically advanced surveillance and control environment, as required by the command's mission objectives for security and monitoring. The existing prison security system (e.g., perimeter surveillance, locking mechanisms, inmate management) is built on proprietary Wright Line control surfaces. Proposed supplies MUST be Brand Name Wright Line to be considered capable of fulfilling this requirement. Interested parties need only provide proof of capability and/or provide a Capability Statement to determine capability. Please indicate business size and any socio-economic considerations on provided material.

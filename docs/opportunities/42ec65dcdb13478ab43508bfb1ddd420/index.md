# Forklift

- Agency: JUSTICE, DEPARTMENT OF
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-04 08:59:51.16-04
- Solicitation Number: 15B50226Q00000045

## Summary

The Government is interested in purchasing one gasoline powered forklift that meets or exceeds the following specifications: Gasoline powered (propane/electric will not be considered). Solid pneumatic tires.- A safety system that meets or exceeds the standards set by Toyota's System of Active Stability (SAS). This system includes an active control rear stabilizer and an active mast function controller. 2-Stage mast with a maximum fork height of at least 131.5". 3-stage masts will be open to consideration as well. 5,000 pound lifting capacity, or greater. 40" wide carriage, or similar, if changes are required due to exceeding other listed specifications. An automatic fork leveling system.- Class 2 forks, 48" length with 6 degrees forward tilt and 11 degrees backward tilt. 40" cascade sideshifter or similar.- Automatic transmission. High volume back-up/reverse alarm. LED Headlights, LED rear combination lights, and an amber LED strobe light. One mounted fire extinguisher. Four-way adjustable operator seat. A safety mechanism that detects if an operator is seated and automatically disables machine movement or functions if they leave. Non-slip floor mat. Weatherized electrical system built for outdoor use in rainy conditions. Warranty: Basic - 12 months / 2,000 hours (or greater). Powertrain - 36 months / 6,000 hours (or greater).

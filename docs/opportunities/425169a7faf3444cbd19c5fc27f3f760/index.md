## Summary

The purpose of this amendment is to incorporate clause 52.240-93, Basic Safeguarding of Covered Contractor Information System which replaces clause 52.204-21, Basic Safeguarding of Covered Contractor Information System. Additionally, this amendment removes 52.249-13, Excusable Delays and provides the Site Visit Roster.

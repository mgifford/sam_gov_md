- Type: Combined Synopsis/Solicitation
- Posted: 2026-04-28 16:53:07.238-04

## Summary

This is a combined synopsis/solicitation for commercial items prepared in accordance with the format in FAR Part 12. This announcement constitutes the only solicitation. Quotations are being requested and a separate written solicitation will not be issued. Solicitation number 1232SA26Q0217 is issued as a Request for Quotation (RFQ) for 12 bioreactor two-liter autoclavable glass bioreactor vessels that must be compatible with Sartorius Biostat-B Bioreactor Control Units and required parts as listed in detail in attachment 2 - Specifications. This acquisition is not set-aside for small business concerns. The applicable North American Industry Classification Standard Code is 334516. The small business size standard is 1,000 employees. This acquisition is an unrestricted requirement. All responsible sources may submit a quotation which will be considered by the agency.

# MathWorks MATLAB

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-04 13:12:03.47-04
- Solicitation Number: M6890926Q7709

## Summary

MCTSSA requires a standardized, high-fidelity computational capability to support engineering analysis, modeling, simulation, and data processing across Marine Corps tactical systems. Current capabilities lack a unified, scalable environment to efficiently develop algorithms, process complex datasets, and perform repeatable analytical workflows necessary to support system testing, evaluation, and informed acquisition decision-making. To address this gap, MCTSSA requires the procurement of commercial off-the-shelf (COTS) brand name MathWorks, Inc. MATLAB® software licenses, associated mission-essential toolboxes, and annual software maintenance services (SMS). This solution provides a widely adopted, industry-standard platform that enables advanced numerical computing, model-based design, signal processing, and data analysis within secure Government-controlled environments.

# Residence Remodeling

- Agency: STATE, DEPARTMENT OF
- Type: Solicitation
- Posted: 2026-05-05 10:56:25.652-04
- Solicitation Number: 19AU9026Q0005

## Summary

This solicitation specification includes the construction of drywall partitions including electrical installations, AC installations, sanitary installations, interior doors, in a USG-owned residences in Vienna, Austria. The work consists of, but is not limited to the following: New Bedroom 3 area = 13,90 m² • Modified Living/dining/kitchen area = 33,00 m² • Modified kitchen area = 14,00 m² • Modified Bathroom 2 area = 4,74 m² Estimated size of the project is between $25,000 and $100,000.

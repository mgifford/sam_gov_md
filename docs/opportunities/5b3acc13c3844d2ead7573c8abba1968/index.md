# License & service maintenance: IBM Rational DOORS Requirements Management Software

- Agency: DEPT OF DEFENSE
- Type: Presolicitation
- Posted: 2026-05-27 12:14:10.593-04
- Solicitation Number: SIMACQ-PD-44-0213

## Summary

This is a Sole Source requirement for the procurement of seventy five (75) Analog Sensor Cables (ASCs), that are part of the Leonardo DRS Advanced Data Acquisition Control System (ADACS). The ADACS comprises of the Control Unit, Universal Sensor Interface Module (USIM), Thermal Ionization Detectors, and the ASC assemblies. The ASC assembly provides the power and Built-In Test (BIT) interface to the TID from the USIM. This allows the ADACS to detect conditions that can lead to an arc fault inside the Electric Plant Switchboards and Load Centers.

The Govenment intends to award a Firm-Fixed Price contract for Fully Automated Core Laboratory System, Cost-Per-Reportable (CPRR) for automation clinical chemistry and immunodiagnostic testing system for Martin Army Community Hospital (MACH), Fort Benning, Georgia 31905.

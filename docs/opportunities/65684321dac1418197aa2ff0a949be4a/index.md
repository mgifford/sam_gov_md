The Department of Veterans Affairs (VA), VISN 22 Network Contracting Office, is seeking sources that can provide a Rotary Microtome Instrument that at a minimum meets the following salient characteristics with a brand name or equal product for the VA San Diego Healthcare System: Must have an antistatic waste tray Must be semi-motorized with capability for manual operation. Must have coarse feed wheel with selectable turn direction. Must have the capability to move object head between 200um/s and 1800um/s. Must have user adjustable force balance system a. Must be capable of being used with both low and high profile blades.. Must have interchangeable parts that allow for the replacement of blade holder components individually. The dimensions of the equipment must not exceed the following, width 477mm x depth 620mm x height 295mm. Must have a digital display.Is a display needed? If yes, does it need to be digital?

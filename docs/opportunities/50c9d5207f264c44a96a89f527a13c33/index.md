# Carbon Fiber Cutting System

- Agency: ENERGY, DEPARTMENT OF
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-22 14:41:50.18-04
- Solicitation Number: PR471273

## Summary

ORNL is requesting a quote for the same or domestic equivalent of a Carbon Fiber Cutting System with the below specifications and technical capabilities. FAR 52.211-6, Brand Name or Equal applies. Key custom features include: Custom-built to ORNL’s roll/core specs o Unwind (mother roll) core ID 10”, cardboard core, ~12” wide roll. o Rewind (product) core ID 3” on a custom aluminum spool, ~11” wide, with notched/keyway ends (machine must accept/drive/locate this spool correctly). Carbon-fiber-appropriate cutting system o Use tungsten carbide cutting edges or other edge suitable for durability when cutting carbon fiber (instead of the “Japanese tool steel” blades referenced generically for other applications). o Vendor to maintain extra blade sets in stock for the custom machine (supportability expectation). Waste handling different from the standard model behavior o Standard behavior described: scraped trim on each side is cut and re-rolled along with the good cuts. o ORNL requirement/customization: waste cannot be wound together with the good product; needs separate waste management, with the proposed custom approach being rewinding waste into separate waste roll(s) (one/both sides) or otherwise directing it separately. Adjustable slit width via knife/spacer arrangement o Width adjustment called out as required; Vendor proposed spacers between knives as the adjustment mechanism. Independent drives/controls o Cutter speed and winding speed independently controlled, each with its own motor, and adjustable feed rate (called out explicitly as a capability of the proposed configuration).

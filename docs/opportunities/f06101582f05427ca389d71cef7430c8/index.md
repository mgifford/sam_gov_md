# DDWG Stretch Wrap Machines SP3300-26-Q-0116

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-04 11:11:53.417-04
- Solicitation Number: SP330026Q0116

## Summary

This Request for Quotation (RFQ) is being issued to establish a firm-fixed-price (FFP) purchase order for the purchase or stretch wrap machines at DLA Distribution Warner-Robins GA (DDWG). The Government intends to award one (1) contract as a result of this RFQ and will be issued on a Standard Form (SF) 1449. This acquisition is not a Defense Priorities and Allocations System (DPAS) rated procurement. This acquisition is being solicited as a Small Business Set-Aside. The North American Industry Classification System (NAICS) code for this project is 333993 and the size standard is 600 employees. The Product or Service Code (PSC) for this acquisition is 3540. Please see attached CSS for full details.

# Dynatrace Software

- Agency: HOMELAND SECURITY, DEPARTMENT OF
- Type: Justification
- Posted: 2026-05-29 15:41:05.953-04
- Solicitation Number: RUIO-26-BM051

## Summary

The Department of Homeland Security (DHS) has a requirement to renew and purchase additional Dynatrace licenses and support services for the DHS Enterprise. Dynatrace is an advanced application performance monitoring (APM) platform that delivers real-time visibility into the performance, availability, and reliability of mission-critical applications and infrastructure. The software enables automated monitoring, root cause analysis, and reporting for applications hosted onpremises, in the cloud, or in hybrid environments.

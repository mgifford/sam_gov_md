Background: The Capabilities Program Executive, for Simulations, Training, Test, and Treat (CPE- ST3), Soldier Virtual Training (SVT) Weapons Skills Development (WSD) has a requirement to replace the ageing Engagement Skills Trainer 2 (EST2) with a modern replacement which removes or overcomes the many limitations of the EST2 system of record. A previous attempt to replace the system was determined unsuccessful, resulting in a reset of the requirement. Additionally, the US Congress has mandated providing an interim solution to replace the EST2 with a solution that can be used while the WSD program is reset. The requirements for the interim solution and reset solution are so similar that it creates efficiencies by putting both requirements together into a single solicitation that can be used to award contracts or OTAs that meet the government’s requirement for an interim solution as well as allowing for the development of a system that will replace the EST2. The product required is a Commercial off the Shelf (COTS) item currently for sale in the commercial marketplace which will allow Soldiers to train on their assigned weapons system in a virtual space. These items will not require any changes from the commercially sold weapons skills Development currently on the market. The Development that is not a final product but which the evaluators see as value in developing may be offered an OTA to develop the Development into a replacement to the EST2. Likewise, the Joint Fires Trainer (JFT) has requirement to fulfil an interim need with COTs items while also opening the possibility for entry into a prototype OTA for those Items evaluated as acceptable but not a true COTS item at entry. The JFT piece will follow the same process but use its unique requirements as stated below. Because both the WSD and JFT use similar components methods, the SVT team has been directed to combine these two requirements into the SVT program. Problem Statement: This Call for Solutions seeks to address the need for an interim COTS solution for WSD and JFT, while also providing for proposal of prototype or developmental solutions fit for establishment of an Other Transaction (OTA). To accomplish this, there are four distinct responses available for companies to propose against.

2.1 The first response is for the establishment of a marketplace for COTS WSD items currently available for sale.

2.2 The second response is for the establishment of a marketplace for COTS JFT items currently for sale.

2.3 The third response is for proposals for evaluation and possible selection for entry into a WSD OTA, which seeks to replace EST2.

2.4 The fourth response is for proposals for evaluation and possible selection for entry into a JFT OTA. To avoid confusion each requested response is separated into its own section (COTS_WSD para. 3-13) (COTS_JFT para. 14-24) (OTA_WSD para. 25-35) (OTA-JFT para. 36-46). Respondents are advised to use the information from each section independently and do not mix one for the other. Responding companies are invited to respond to one, some, any or all the calls for solutions detailed below. When responding, you must label each response as detailed within each section.

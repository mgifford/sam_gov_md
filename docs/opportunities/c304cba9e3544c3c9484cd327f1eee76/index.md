# USNS HENRY J KAISER-Eaton Motor Controller Additional Material

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-20 12:06:51.082-04
- Solicitation Number: N3220526Q0056

## Summary

Military Sealift Command is seeking eligible businesses that can provide the following Eaton Corporation Brand Name Motor Controllers Additional Material for use onboard the USNS HENRY J KAISER (T-AO 187). The Motor Controllers are associated with the ships Cargo Pumps. The delivery location will be MSC SSU BATS Warehouse, 9284 Balboa Ave., San Diego, CA 92123. Eaton Corporation is listed as the Original Equipment Manufacturer (OEM) and the material is listed this way in the solicitation. See attached Solicitation and redacted Justification and Authorization.

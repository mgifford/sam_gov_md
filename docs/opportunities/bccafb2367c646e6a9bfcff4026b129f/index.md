- Agency: DEPT OF DEFENSE

- Posted: 2026-05-20 11:11:15.699-04

## Summary

SPARC T8-2 Server Premier Support (Sytems and Disk) and Data Retention Maint. Renewal qty 6. The servers requiring support are used to host numerous applications and databases within the Application Server eXchange (ASX) hosting environment. The support provides 24/7 support services designed to ensure system and data accessibility, minimize downtime and guarantee consistent access to information. The 72 ABW/SC manages the local area network infrastructure, Information Processing Node (IPN) and the Program Management for all servers, switches, software and access used by Tinker Air Force Base. This includes the ASX servers, software, databases, and customer applications.

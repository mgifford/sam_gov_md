# Fiber Optic Cable B230 to B9511

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-08 15:53:26.103-04
- Solicitation Number: FA302226Q0009

## Summary

Engineer, furnish, install and test (EFI&T) 12-strand single mode (SM) fiber optic cables (FOC) from Infrastructure Transfer Building (ITB) 230 to Building (B) 9511 at Columbus AFB, MS. The Contractor shall install approximately 3,100 feet (maintenance loop included) of 12-strand SM FOC from ITB 230 to B9511. Terminate 12 strand SM FOC in the new 12-port FODP in ITB 230, and outdoor FODP in B9511.

# LOWELL CREEK FLOOD DIVERSION AT SEWARD, ALASKA

- Agency: DEPT OF DEFENSE
- Type: Special Notice
- Posted: 2026-05-11 20:33:33.844-04

## Summary

The Lowell Creek Flood Diversion project, SEW018, originally planned to construct a new flood diversion system in Seward, Alaska, is on hold at this time. Please continue to monitor SAM.gov for updates regarding a new project that will be designed to rehabilitate the existing tunnel.

# B1130 Annex HVAC Repair

- Agency: DEPT OF DEFENSE
- Type: Presolicitation
- Posted: 2026-04-27 09:12:56.064-04
- Solicitation Number: FA480326R0020

## Summary

Project Title: B1130 Annex HVAC Repair Project Location: Shaw AFB, SC This is a presolicitation notice to make repairs to the existing heating, ventilation, air conditioning (HVAC) system in Building 1130 Annex. A retro commissioning by a third party was performed which revealed many issues with the system. The government has resolved many of the issues, but several critical items remain. This project will correct those outstanding items in accordance with the attached Statement of Work dated 9 March 2026. Period of Performance: 210 Calendar Days after Notice to Proceed issuance. Competition: This requirement is a 100% Small Business Concern Set Aside for North American Industry Classification System (NAICS) code 238220.The Magnitude of this requirement is valued between $1,000,000.00 and $5,000,000.00. Solicitation: The solicitation publish date is to be determined at a future date.

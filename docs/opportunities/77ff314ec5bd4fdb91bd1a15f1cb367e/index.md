# Integrated Base Defense Establishment of a Closed Restricted Network to Support the Electronic Security System

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-20 16:45:41.05-04
- Solicitation Number: FA469026R0006

## Summary

This requirement is to design, configure, test, document, and implement a new Closed Restricted Network (CRN) to support base-wide Electronic Security System (ESS) operations at Ellsworth AFB, SD. The purpose of this amendment is to update and add the following:1. Updates box 8 Offer Due/Date from 10 June to 16 June 2026, 1:00PM MDT.2. Updates clause 252.204-7025 - NOTICE OF CYBERSECURITY MATURITY MODEL CERTIFICATION LEVEL REQUIREMENTS. 3. Updates clause 252.204-7021 - CONTRACTOR COMPLIANCE WITH THE CYBERSECURITY MATURITY MODEL CERTIFICATION LEVEL REQUIREMENTS. 4. Updates submission deadline of site visit from 26 May to 22 May 2026, 4:30PM MDT. 5. Removes line (b)2 of the Site Visit Reporting Instructions.6. Add Attach 6 - ESS_Questions and Answers.

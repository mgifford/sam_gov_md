## Summary

This is a solicitation for commercial items prepared in accordance with the format in FAR part 12. This announcement constitutes the only solicitation. Quotes are being requested, and a separate written solicitation will not be issued. The solicitation number FA251726QA011 is issued as a request for quotation (RFQ) for Dell Wyse Clients and configuration for the 319th Combat Training Squadron on Peterson Space Force Base (SFB), CO. Please see Table 1 below for the required line items. This acquisition is set-aside for small business concerns, and is solicited as a firm fixed price 100% Small Business Set Aside purchase order.

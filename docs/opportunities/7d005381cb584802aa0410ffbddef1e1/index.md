1.0 INTRODUCTION Manchester VAMC Pharmacy has a need to relocate both a portable exhaust hood and their medication cache. The exhaust hood is currently in the same HVAC zone as other hoods, which impacts its ability to truly meet redundancy requirements. The current medication cache is improperly located within the facility. This project will install ducting for the relocated hood, a supplemental negative-air exhaust fan, and a newly installed package HVAC unit. It will repurpose waiting room 101 into an office with two spaces and room for three desks, and will prepare room NW12 to meet pharmacy cache requirements. See Appendix A (attached) for proposed details on office relocation, exhaust hood/fan ducting path, and floorplans. Phasing will be required to prepare new office space in 101, move employees into this space and out of E127, and finally to finish the ducting in E127. These phased tasks will be done in parallel with the rebuild of room NW12.

3.0 SCOPE AND PROJECT TASKING

3.1 Exhaust Hood Relocation 3.1.1 Relocate existing Pharmagard Negative Pressure Total Exhaust Sterile Isolator Bench/Console (Product Manual included as Appendix B), and required accompanying exhaust fan, and install all related ducting. 3.1.2 Install new package unit, appropriately sized and located to serve the new requirements in E127, including 12 air-changes per hour (ACH) and continual negative differential pressure.

3.2 New Office Space in Room 101 3.2.1 Install two new partition walls in Room 101, forming two new offices.

3.3 Cache Relocation Pharmacy's Cache is currently located in N78 and needs to be moved to NW12. NW12 requires the following upgrades to meet cache requirements: 3.3.1 Replace door. New door must be completely opaque and hollow metal, must meet 15-minute forced-entry resistant requirements, and must have a deadbolt that releases from the inside when the handle is pushed down for exit. 3.3.2 Install Security requirements: Â Â Â Â 3.3.2.1 Entrance door must be controlled by physical access control (must interface with existing LENEL PACS). Â Â Â Â 3.3.2.2 Entrance must be monitored by intrusion detection system (both boundary and volumetric). System must be compatible with existing DMP Receiver. 3.3.3 Repair/cover NW12 walls. 3.3.4 Permanently close southmost mailroom (NW5) door with drywall. Security requirements necessitate that "The perimeter of the Cache enclosure must be no less than 50 feet from the Loading dock and from the Mailroom." 3.3.5 Replace nearby fan coil unit (Room W50) and install ducting. 3.3.6 Ensure cache achieves required 12 air-changes per hour.

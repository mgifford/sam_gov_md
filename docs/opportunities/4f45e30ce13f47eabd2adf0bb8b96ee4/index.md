# RFI-Telematics System for Managing Powered Industrial Vehicles

- Agency: POSTAL SERVICE
- Type: Sources Sought
- Posted: 2026-05-22 15:17:55.834-04
- Solicitation Number: 3CW-26-A-0017

## Summary

Telematics PIV - The United States Postal Service (USPS) is seeking currently available applications and market information regarding the potential sourcing of telematics system capable of managing and monitoring Powered Industrial Vehicles across multiple facilities. The product should provide solutions that improve operational safety, fleet visibility, maintenance tracking, operator accountability, and reporting features. The attached Request For Inforamtion document and the RFI- System for Managing PIVs documemt must be reviewed.

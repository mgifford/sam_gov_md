# USAF Wide Area Network Request For Information (RFI)

- Agency: DEPT OF DEFENSE
- Type: Special Notice
- Posted: 2026-04-30 12:43:09.251-04

## Summary

AFLCMC has a requirement to stand-up a Wide Area Network (WAN) of layer 2 and layer 3 transport services to connect 50 or more sites of government and commercial facilities (ex. cloud data centers, SATCOM, and DIB partners). Each connected site will require varying service level agreements and connectivity needs to other sites. Please see attached document.

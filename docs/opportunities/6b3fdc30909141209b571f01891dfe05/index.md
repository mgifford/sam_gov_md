# Remote Video Game Kits

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-15 12:19:45.984-04
- Solicitation Number: FA8052SS05082026

## Summary

The Department of the Air Force (DAF) Library Program requires video game kits for remote and isolated locations. They need 1 box kit each for 20 locations monthly. Each box kit will contain 6 new released video games, all 20 locations will receive the same 6 games each month. DAF Libraries is looking for an established seller of video games to the library and commercial marketplace. *Ammendment to Post* (15 May 2026) Word document: "Remote Video Game Kits-Q and A" has been attached to this notice.

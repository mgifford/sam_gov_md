THIS IS NOT A REQUEST FOR COMPETITIVE OFFERS Tabletop Ultrasonic Cleaning unit This is a Pre-Solicitation Notice for the Department of Veterans Affairs, Network Contracting Office (NCO) 4, has a requirement for Sterile Processing Services Tabletop Ultrasonic Cleaning unit.

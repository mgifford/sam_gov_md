# Multi-Mission Reconnaissance Craft (MMRC) Bravo variants

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-04 12:52:19.793-04
- Solicitation Number: N00024-26-I-MC01

## Summary

The Naval Sea Systems Command (NAVSEA) is providing industry notification of an Other Transaction (OT) production agreement directly to The Whiskey Project Group (TWPG) LTD, UEI UGKGLXZ7LRU9, Cage code Z1CB8 or The Whiskey Project Group USA LLC, UEI LP45NKCN9QH7, Cage code 12W64 under NAICS code 336612, Boat Building SIC Code 1940 Small Craft (RIBs). The Commercial Solutions Opening (CSO)-based prototype OT effort was competitively awarded by Defense Innovation Unit (DIU), Mountain View, CA to two (2) businesses in August 2023 and TWPG received a Successful Completion of Prototype Memorandum for their Multi-Mission Reconnaissance Craft (MMRC) Bravo variant in June 2025 (OT HQ0845-23-9-0032). This phase is for the OT production of up to 10 or more TWPG MMRC Bravos, to include accompanying communication, navigation, and sensing equipment; craft auxiliary equipment; and craft maintenance, training, and sustainment support, which were specially designed and tested to fit USMC’s need under DIU’s “Expeditionary Small Boats” project. The production OT agreement is expected to be signed by Summer 2026. The POC contact is TWPG CEO Mr. Darren Schuback, Darren.schuback@thewhiskeyprojectgroup.com or at 0011-61409999734 (Non-US Phone).

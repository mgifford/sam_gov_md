# Microsoft 365 Education License - Renewal

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-08 15:21:03.539-04
- Solicitation Number: M00264-26-Q-0073

## Summary

The Marine Corps University (MCU) has a requirement for Microsoft 365 A5, Planner and Project Plan 3 and Visio Plan 2, Defender for Business, Power Automate Premium, and Power apps Premium annual licensing. Microsoft 365 A5 is a suite of office applications such as Outlook, Word, Excel, PowerPoint, OneNote, Publisher and Access. Microsoft 365 A5 also includes Services such as Exchange, OneDrive, SharePoint, Teams, Planner, Sway, Forms, Stream, and Flow. Microsoft 365 A5 will provide the MCU with seamless, integrated capabilities that can be accessed on multiple devices while providing security and protection from advanced threats for both students and faculty.

# Appeals Centralized Database System (ACDS)

- Agency: TREASURY, DEPARTMENT OF THE
- Type: Sources Sought
- Posted: 2026-05-19 07:36:51.572-04
- Solicitation Number: 26-27-A-PMO-ACDS-SSN

## Summary

At a summary level, the Government seeks to identify 8(a) small businesses capable of providing ColdFusion comprehensive support and implementation services. The Internal Revenue Service (IRS) seeks contract support from a vendor with expertise in ColdFusion to provide comprehensive support and implementation services. The aim is to improve operational efficiency, refine customer engagement processes, and ensure system scalability and adaptability for future business needs. The candidates must possess advanced proficiency in ColdFusion programming and have substantial experience with SQL Server and the Windows operating system. Their responsibilities will include ColdFusion development, system and database administration, assisting in the transition to SQL Server, and upgrading to Windows Server 2019. The objective is to successfully migrate from ColdFusion 2016 to ColdFusion 2023, transition from Windows Server 2012 R2 to Windows Server 2019, and address any issues arising during this process.

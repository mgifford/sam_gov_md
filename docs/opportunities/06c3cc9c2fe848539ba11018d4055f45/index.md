# Power Cable Assembly

- Agency: DEPT OF DEFENSE
- Type: Presolicitation
- Posted: 2026-05-19 15:52:28.77-04
- Solicitation Number: W31P4Q-26-R-0046

## Summary

ALC has a requirement to provide the Cable Assembly, Power for the PATRIOT missile. The item is used as a configuration-controlled cable assembly that provides critical electrical power and signal connectivity between integrated subsystems within a military platform, supporting overall system functionality and operational reliability. This requirement is designated for sole-source competition because it requires the use of SRD approved sources.

## Summary

This is a combined synopsis/solicitation for commercial items prepared in accordance with the format in Subpart 12.202, as supplemented with additional information included in this notice. This solicitation is being issued as a Request For Quotation (RFQ). This acquisition is 100% set aside for small buisness. Requirement Information The North American Industry Size Classification System (NAICS) code associated with this requirement is 336211. The Small Business Size Standard associated with this NAICS is 1,000 employees. Fire and Emergency Services Flight (CEF) require modifications to the Incident Command Vehicles (ICV) acquired in 2026. The vehicle a 2026 Chevrolet Silverado 1500 crew cab truck must be outfitted to support emergency response capabilities, incident command operations and meet mission?specific markings, communications, and equipment storage requirements. These modifications will enable CEF to store and deploy equipment in a configuration that supports operational effectiveness, enhances responder safety, and extends the service life of critical life?safety and incident response assets assigned to these vehicles. Please see attached perfomance work statment for more information.

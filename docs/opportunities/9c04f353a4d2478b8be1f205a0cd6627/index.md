## Summary

***This soliciatation is being reopened after it was determined that the line items in the original solicitation did not accurately portray the number of weapons to be serviced each year. Each contract year now contains 3 line items to be quoted, with the quantity of each type of weapon to be serviced specified on each line item. Statement of work is attached.*** DLA Distribution San Joaquin located at Tracy, CA has a requirement to establish a Firm-Fixed Price (FFP) purchase order for annual preventative maintenance, inspection, and repair services for DLA Police's inventory of small arms. See attached solicitation. This RFQ is being solicited as a 100% Small Business Set-Aside. The North American Industry Classification System (NAICS) code for this project is 811310 and the size standard is $12.5M. The Product Supply Code (PSC) for this acquisition is J010. Please direct any questions and email all quotes to John.Sproul@dla.mil. 1-Award will be made on an 'all or nothing' basis and the base and all option periods must be quoted. 2-Taxes do not apply as DLA is a Federal Agency and is tax exempt. 3-Payment will be made by Wide Area Workflow (WAWF). 4-All quotes shall be all encompassing of all costs for the requested services.

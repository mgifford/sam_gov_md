# CFX Duet Real-Time PCR System and Accompanying Software

- Agency: AGRICULTURE, DEPARTMENT OF
- Type: Combined Synopsis/Solicitation
- Posted: 2026-04-30 14:50:46.946-04

## Summary

This is a combined synopsis/solicitation for commercial items prepared in accordance with the format in FAR Part 12. This announcement constitutes the only solicitation. Quotations are being requested and a separate written solicitation will not be issued. Solicitation number 1232SA26Q0496 is issued as a Request for Quotation (RFQ) for: Three (3) Bio-Rad CFX Duet Real-Time PCR System - PCR detection system with 96-well block and 2-color detection plus FRET. Includes CFX Duet base unit and cables. One (1) CFX Maestro Software 2.3 for Windows PC - One (1) license, CFX Maestro 2.3, software for real-time PCR plate setup, data collection, statistics, and graphing of results; for Windows PCs. Vendor must provide brand name or equal systems and accompanying software, systems must have a minimum of a one-year warranty from completion of installation, systems must have the training needed for use and set up of system for new employees, and the cost must be included in the total cost of item as detailed in the Specifications attachment. This acquisition is not set-aside for small business concerns. The applicable North American Industry Classification Standard Code is 334516. The small business size standard is 1,000 employees. This acquisition is an unrestricted requirement. All responsible sources may submit a quotation which will be considered by the agency.

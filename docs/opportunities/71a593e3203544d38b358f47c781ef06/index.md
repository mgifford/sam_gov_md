# Intent to Procure: Radio Control Set (NSN: 5826-01-439-2708)

- Agency: DEPT OF DEFENSE
- Type: Presolicitation
- Posted: 2026-05-14 12:52:16.909-04
- Solicitation Number: SPRWA1-26-R-0029

## Summary

The Government intends to release a firm-fixed-price Request for Proposal (RFP), on a sole-source basis, to Rockwell Collins Inc. (DBA) Collins Aerospace CAGE 13499 on or before 29 May, 2026, 8:00AM EDT. This requirement is for the manufacture of the Radio Control Set used on the C-130J SOF Aircraft. NSN: 5826-01-439-2708 Part Number: 622-5147-002 Noun: Radio Control Set QTY: 24 The Radio Control Set is utilized on the C-130J SOF aircraft as a homing beacon for receiver aircraft and provides rendezvous capability with an air-to-air transmit function (beacon) mode. Impediment to Competition: The Original Equipment Manufacturer (OEM) for this item is Rockwell Collins Inc. (DBA) Collins Aerospace CAGE (13499). They are the only known source with the technical data, expertise, facilities and equipment required to support this acquisition. The Government does not own any data, drawings, schematics, or any other releasable technical data in support of this requirement. Consequently, Rockwell Collins Inc. (DBA) Collins Aerospace is the only source with adequate knowledge of the requirement and possession of the required technical data and capabilities needed to produce this item and ensure compatibility. DISCLAIMER: This notice is for informational purposes only and does not constitute a RFP or a commitment by the Government. Responses in any form are not offers, and the Government is under no obligation to award a contract as a result of this announcement. No funds are available to pay for preparation of responses to this announcement. Any information submitted by respondents is strictly voluntary.

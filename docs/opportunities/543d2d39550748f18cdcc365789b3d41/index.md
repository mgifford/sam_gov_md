(v) The equipment consists of a real-time PCR system capable of supporting multiplex nucleic acid detection and analysis. The system must provide accurate thermal control, reliable fluorescence detection, and compatibility with existing laboratory software and experimental workflows. The following product features/characteristics are required for this requirement: System can capture up to five fluorophores in a single reaction well using “All Channels” scan mode, or, for faster scanning time, one fluorophore when using the SYBRR/FAM or FRET Scan Modes. Fixed optical path, directly over each well, eliminates the need to normalize for positional bias or passive dye calibration. System does not have lid or drawer that extends beyond the footprint of the system nor requires additional operating clearance. Dimensions (W x D x H) is 13x22x14 inches; can easily fit under a standard shelf Real-time data traces can be viewed during a run from the thermal cycler base or on CFX Maestro (if a computer is connected to the instrument). CFX Maestro software is compatible with all real time PCR results from the older model CFX system the lab has been using; it shall ensure project continuity. Multiple plates can be combined into one experiment with the Gene Study Feature on the free CFX Maestro software. Software performs t-tests and 1-way ANOVA calculations. The requested system, from Bio-Rad shall provide multiplexing capability, thermal uniformity, and compatibility with existing laboratory workflows and data analysis software to support current and future research requirements.

# News Monitoring Services

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-19 16:47:29.346-04
- Solicitation Number: W91QEX26QA011

## Summary

The 410th Contracting Support Brigade (CSB), Regional Contracting Office (RCO) - Miami, in support of the US Southern Command, Public Affairs, have a requirement for a competitive Firm Fixed Price Purchase Order. The award is for a base year plus four (4), 12-month options. This requirement is to provide a non-personal services contract to furnish all personnel, equipment, supplies, facilities, and other items necessary to perform news monitoring services using a cloud-based subscription platform. In addition, the Contractor shall deliver an Al-enhanced webbased interface that aggregates and analyzes broadcast news and social media content. This enhanced capability will automatically generate insights, sentiment analysis, and recommendations by processing millions of data points using natural language processing and machine learning algorithms. Read the Performance Work Statement in its entirety.

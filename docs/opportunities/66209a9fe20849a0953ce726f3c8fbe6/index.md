## Summary

Sources Sought Notice 36C10B26Q0320 Amendment 1 SOURCES SOUGHT NOTICE The Sources Sought closed on April 14, 2026, and is no longer an active requirement. The purpose of this Amendment is to update and close the loop on the Sources Sought Notice for Brand Name or Equal NeoSoft LLC Cardiac Magnetic Resonance image processing software, including software licensing, software maintenance, and technical support. Based on the responses to the Sources Sought Notices, the Government intends to refine its requirement and then release a solicitation via General Services Administration (GSA) eBuy website. We appreciate the responses received; however, no further action will be taken as a result of this notice. Any future related requirements will be publicized separately in accordance with applicable regulations.

# Legacy R22 Split System Replacement

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-11 13:09:18.892-04
- Solicitation Number: F2M3CB6061A003

## Summary

THIS IS NOT A REQUEST FOR QUOTE: The purpose of this Sources Sought Notice is to query the market for potential interested, capable, responsible, and qualified small businesses that can provide and perform the stated requirement IAW the atatched DRAFT Statement of Work. The Government is interested in collecting market information in accordance with (IAW) RFO Part 10. If interested, please review all attachments and fill out and return a copy of the attached Request For Information (RFI) document along with your capabilities. Please note that this is not a construction requirement. Please return the filled out RFI and capability statement to the POCs in this notice. Description of Services: The contractor shall provide all personnel, equipment, tools, materials, supervision, and quality control necessary to replace the HVAC system in Building 4983 at JBSA Lackland. The 502d Civil Engineer Squadron requires the decommissioning and removal of the existing 15-ton direct expansion (DX) split system. The legacy system operates on phased-out R-22 refrigerant and consists of a Rheem Air-Cooled Condensing Unit (Model No. RAWE-180CAZ, Serial No. 6698F010904536) and a corresponding RUUD Air Handling Unit (Model No. RHCE-150ZK, Serial No. 114G029900259). This project includes the complete installation of a new, fully functional, code-compliant 15-ton HVAC system equipped with modern Direct Digital Controls (DDC) and BACnet-compatible building automation capabilities. Attachments: 1. Request for Information_Legacy R22 Split System Replacement 2. DRAFT Statement of Work 3. Legacy R22 Split HVAC System PowerPoint 4. DRAFT Salient Characteristics_15-Ton Commercial DX Split System

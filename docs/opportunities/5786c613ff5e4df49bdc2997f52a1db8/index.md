# Regional Refuse Collection, Disposal, and Recycling Services for Naval District Washington (NDW)

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-13 13:31:46.499-04

## Summary

This solicitation is for the provision of regional refuse collection, disposal, and recycling services for Naval District Washington (NDW). Services shall be performed at multiple installations located within a 100-mile radius of the Washington Navy Yard, D.C. Amendment 0001: Corrected set aside code to reflect 8(a) set aside.

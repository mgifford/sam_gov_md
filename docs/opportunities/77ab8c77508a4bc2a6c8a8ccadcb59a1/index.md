# Commvault CommServe Servers

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-04-28 16:25:31.56-04
- Solicitation Number: FA330042CS26II

## Summary

The 42d Contracting Squadron, Maxwell AFB, AL, is conducting market research to identify potential sources capable of providing a turnkey solution to replace the 42d Communications Squadron’s End-of-Life (EOL) Hewlett Packard Enterprise (HPE) Commvault CommServe and Media Agent Servers. The Government requires brand name HPE ProLiant DL360 Gen12 servers, or equal, to ensure 100% compatibility with the existing, standardized HPE Storage Area Network (SAN) and core server infrastructure. This requirement includes not only the delivery of the servers but also all associated migration services, installation, configuration, testing, and training. Information gathered from this notice will be used to finalize the acquisition strategy for the requirement detailed in the attached draft Statement of Requirements (SOR).

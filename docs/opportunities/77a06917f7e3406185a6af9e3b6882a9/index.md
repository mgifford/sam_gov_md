# NIPR Virtual CORE Storage Hardware Upgrade

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-04-28 15:17:13.605-04
- Solicitation Number: FA330042CS26

## Summary

The 42d Contracting Squadron (42 CONS), Maxwell AFB, AL, is conducting market research to identify potential sources capable of providing a turnkey NIPR Virtual CORE Storage Hardware Upgrade for the 42d Communications Squadron. This requirement is for the procurement, installation, and seamless integration of Hewlett Packard Enterprise (HPE) or Equal equipment, specifically targeting the capabilities of the HPE MSA 2070 storage arrays and HPE DL360 Gen 11 servers. Because this is a turnkey solution, the contractor shall be responsible for all comprehensive integration services. This includes project management, engineering design, physical installation, virtual environment data migration (VMware vSphere/vCenter), network configuration, system testing, and over-the-shoulder technical training. If proposing an "or equal" solution, the vendor must demonstrate that their proposed hardware and architecture ensures 100% compatibility, interoperability, and seamless native integration with the installation's existing, standardized HPE network infrastructure, without causing mission degradation or requiring significant re-engineering and retraining of government personnel. Information gathered from this notice will be used to finalize the acquisition strategy for the requirement detailed in the attached draft Statement of Requirements (SOR).

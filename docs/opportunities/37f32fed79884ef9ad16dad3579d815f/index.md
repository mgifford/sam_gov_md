# Fiber Optic Installation

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-20 14:07:04.753-04
- Solicitation Number: W912L826QA017

## Summary

Camp Dawson requires fiber optic infrastructure to support exciting connectivity requirements. The project will utilize existing underground conduit infrastructure to install new single mode and multimode fiber optic cabling between designated telecommunication space. See SOW. Award will be made to the responsible vendor whose quote is technically acceptable and offers the lowest price. NIST SP800-171 assesment and reporting requirements including DFARS 252.240-7997, CD 2026-O0025 240.370-5(d) will make an affirmative determination of responsibility.

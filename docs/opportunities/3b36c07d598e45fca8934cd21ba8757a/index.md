# Virtual Environment Trainer

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-14 14:32:09.908-04
- Solicitation Number: FA452826KH0001

## Summary

The 91st MXG (Maintenance Group) has developed the a requirement for Virtual Environment Trainer with expanded training modules for the 91 MXG. The Virtual Environment Trainer is a virtual environment created OTS headgear and controls to simulate the environment of a launch facility. The contractor must provide the software needed for up to 4 personnel to train in a Virtual Launch Facility Environment using training modules on SP 102 R&R and ASU Contact R&R and Adjustment. This trainer allows trainers to provide input into the training that could not be done in the real world and will increase training capacity by reducing demand on limited resources.

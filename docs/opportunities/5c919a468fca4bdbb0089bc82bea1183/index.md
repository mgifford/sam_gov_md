## Summary

The F-35 JPO has a requirement to modify the In-Line File Encryption Device (IFED) software to use government mandated Quantum Resistant algorithms which will facilitate the verification of all signed code inside of the IFED equipment. Contractors will be responsible for testing and integration of modified code. The vendor shall verify that the software update can be applied in the field without opening the enclosure.

## Summary

The purpose of this modification is to change the maximum number of pages allowed for SF330s from 60 to 70 pages. If a firm has already submitted a SF330 for this project, they may re-submit with the new page maximum, but this is not required. Each page cannot exceed 8-1/2 x 11 in size. Photographs or other graphics will be included in the 70-page count. Title pages and tables of contents, if applicable, are excluded from the page count limitation as are All Required Attachments.

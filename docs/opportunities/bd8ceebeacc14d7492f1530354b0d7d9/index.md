## Summary

ARMY CONTRACTING COMMAND - DETROIT ARSENAL (ACC-DTA) proposes to solicit for a Firm Fixed Price Contract for the MSG Swing Arm, Color Green. This solicitation will be restricted to Military Systems Group Inc. (CAGE: 0DDW5) under Federal Acquisition Regulation (FAR) 13.106-1(b)(1). This requirement will be solicited under W912CH-26-Q-0051. This requirement is for the following item: Noun: MSG Swing Arm, Color Green NSN: 1005-01-676-7880, Part Number: 13074785-2, Quantity: 85 EA with 100% option NAICS: 332994 The solicitation, W912CH-26-Q-0051, is anticipated to be released in a minimum of fifteen days. Due to this item being restricted, please reach out to the manufacturer for any potential subcontracting opportunities. ---------------------------------------------------------------------------------- CAUTION: This solicitation will be issued electronically as will any amendments thereto.

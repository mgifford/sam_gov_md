# NOISS Instrument Manager Software Subscription

- Agency: DEPT OF DEFENSE
- Type: Special Notice
- Posted: 2026-04-28 14:52:48.131-04
- Solicitation Number: 0012415508

## Summary

The Fort Hood Health Contracting Branch (FHHCB), Medical Readiness Contracting Office – West (MRCO-W), Army Health Contracting Activity, MEDCOM, Fort Hood, Texas intends to award a Firm Fixed-Price, sole source contract to Locked Core Tech, LLC (formerly Mission First Solutions LLC) for an Instrument Manager Middleware Software Subscription, under authority of FAR § 12.102(a), for purchases not exceeding the simplified acquisition threshold (SAT), only one source reasonably available, urgency, exclusive licensing agreements, brand name, or industrial mobilization. This is for an Instrument Manager Middleware Software Subscription to support CRDAMC, Fort Hood, Texas, 76544. Award will be on or about 30 April 2026. The applicable NAICS code for this requirement is 513210, “Software Publishers”. The Small Business Size Standard is $47M. This notice is not a request for competitive quotes. No requests for capability briefings will be honored because of this notice and any information provided will not be used as part of any subsequent solicitation requirement. No telephonic inquiries will be honored. A determination by the Government not to compete with this proposed contract based upon responses to this notice is solely within the discretion of the Government. THIS IS NOT A REQUEST FOR COMPETITIVE PROPOSALS. This is a notice of intent to award a sole source contract to provide the product Instrument Manager Middleware Software Subscription. The Contracting Officer determined that the circumstances of the contract action deem only one source reasonable available. The Fort Hood Health Contracting Branch (FHHCB), Medical Readiness Contracting Office – West (MRCO-W), Army Health Contracting Activity, MEDCOM, Fort Hood, Texas intends to make a sole source award to Locked Core Tech, LLC (formerly Mission First Solutions LLC), 18304 Cabin Road, Triangle, Virginia, 22172.

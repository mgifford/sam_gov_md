The proposal is to build an adhoc wireless network which has ONE-WAY receive capability from the existing aircraft intercom on C-17, KC-135, and (next phase) KC-46 test aircraft. The carry-on system would NOT require any aircraft modification and is designed using flight approved batteries and the same commercial wifi that is already approved for use in our military aircraft.

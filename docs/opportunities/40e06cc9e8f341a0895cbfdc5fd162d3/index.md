# Multicultural Program Coordinator

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-28 05:33:54.572-04

## Summary

This is a non-personal service contract with one base year and four options years. The Contractor shall support U.S. Air Force newcomer orientation programs by providing multicultural activities, introductory German language and culture classes, bi-weekly cultural tours in the local area, and monthly German cooking classes in accordance with the attached Performance Work Statement (PWS). Documents available upon request via SAM.

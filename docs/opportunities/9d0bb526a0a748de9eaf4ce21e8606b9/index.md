# Basic Ordering Agreement for Aviano AF Base

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-21 10:48:25.491-04
- Solicitation Number: FA5682-26-Q-8013

## Summary

Aviano AB is looking for companies interested in performing occasional small construction, repair and trade works at Aviano AB. Work may include but is not limited to: maintenance, repair, alteration, mechanical, electrical, heating/air conditioning, plumbing, demolition, painting, flooring, paving, landscaping and earth work for industrial/office buildings and/or infrastructure. The anticipated value of these projects will range from EUR 14.000 to EUR 150.000 and up to EUR 299.000 / USD 350,000 for vendors possessing a valid SOA OG1 certificate. We would appreciate your expression of interest by return email to both the following email addresses: sara.giacomello.it@us.af.mil cesar.becerra.1@us.af.mil This agreement is not a contract. Construction to be furnished under these agreements will be ordered by issuing Task Orders.

# Security Camera and Installation

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-13 09:26:11.952-04
- Solicitation Number: N0018926QL083

## Summary

NMCLANT DET Oceana, Weapons Compound requires a security camera with installation services. The service provider shall provide all necessary supplies, materials, equipment, and labor to deliver and install a complete and fully functional security camera system. The contractor must be able to utilize the existing power source located at the old camera installation area. The scope of work includes the removal and disposal of the existing non-operable camera and the installation of the new system. This is a one-time purchase and installation; no recurring monthly maintenance fees are required. Please see attached solicitation and PWS within for further details.

# Parallel Induction Linear Sorter (PILS) Phase 2 Program

- Agency: POSTAL SERVICE
- Type: Award Notice
- Posted: 2026-04-29 13:59:02.882-04
- Solicitation Number: 3APCKG-25-B-0008-MOD11
- Awardee: INTRALOX LLC New Orleans LA 70123 USA
- Award Amount: 49452740.00

## Summary

Intralox LLC has been awarded a non-competitive modification to the contract for Phase 2 of the Parallel Induction Linear Sorter (PILS) program. The PILS is a package sorting system that is being deployed to various U.S. Postal Service mail processing facilities. The value of the contract modification is $49,452,740 and includes the deployment, installation, and testing of twenty-one (21) PILS units.

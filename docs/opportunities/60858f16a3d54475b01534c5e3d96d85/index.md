# Base Telephone Parts

- Agency: DEPT OF DEFENSE
- Type: Solicitation
- Posted: 2026-05-04 16:09:24.942-04

## Summary

Contracting Department, Marine Corps Installations East (MCIEAST) has a supply requirement for the purchase of various telephone parts. This requirement includes Corning, Cortelco, Preformed, and Siemon brand name items. This will be used to replenish stock and to replace parts that need repair throughout the installation. Please see the RFQ for more details.

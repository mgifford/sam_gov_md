## Summary

***THIS is a SOURCES SOUGHT NOTICE ONLY*** This contract seeks to provide Lodging for the U.S. Army War College Class of 2027 National Security Staff Ride (NSSR) Washington, DC Educational Trip. Please see the attached Performance Work Statement for full requirements. If interested, please submit a capability statement with contact details and past performance information.

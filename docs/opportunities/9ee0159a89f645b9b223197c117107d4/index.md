## Summary

Trusties of Indiana was awarded a sole source Firm Fixed Price under FAR 6.103-1 only one responsible source under FAR parts 12/15. This effort will provide the unique SOCAAS and NOCaas Support within scientific Research computing environment. The current SCINET is a high-performance computing network that supports research in agricultural sciences. The network is designed to help researchers analyze large amounts of data and perform complex simulations, allowing them to better understand and improve crop yields, animal health, and other aspects of modern agriculture. SCINet’s infrastructure includes a variety of powerful computing resources, such as high-performance clusters and cloud-based computing services, as well as advanced software and tools for data analysis, modeling, and visualization. This network is separate from USDA’s core network infrastructure and requires specialized security and network operations, and folds into various other networks such as internet 2 and perfSonar

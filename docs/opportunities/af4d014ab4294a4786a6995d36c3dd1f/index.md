# Components for Universal Modular Mast Program

- Agency: DEPT OF DEFENSE
- Type: Presolicitation
- Posted: 2026-05-06 08:46:53.527-04
- Solicitation Number: N64498-26-SIMACQ-PD-45-0123

## Summary

NSWCPD has a requirement for key components for the Universal Modular Mast (UMM) program via full and open competition, with all work to be performed in accordance with official technical drawings and documentation. Due to the Distribution D Statement governing these technical materials, interested parties must submit a valid JCP Certification to Brooke Steele at brooke.a.steele3.civ@us.navy.mil no later than 5:30 PM EST on 21 May 2026 to gain access to the RFQ and associated drawings. All relevant documents will be issued following the closing date of this pre-solicitation. All inquiries must be directed via email as phone calls will not be accepted.

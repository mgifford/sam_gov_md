REQUEST FOR QUOTE CYANOBACTERIA DNA ANALYSIS INTRODUCTION This is a solicitation for commercial items prepared in accordance with the format in Federal Acquisition Regulation (FAR) Part 12 as supplemented with additional information included in this notice.

# C-130H Formation Positioning System Draft RFP

- Agency: DEPT OF DEFENSE
- Type: Special Notice
- Posted: 2026-05-19 14:53:38.769-04
- Solicitation Number: FPS2026130H

## Summary

This special notice is for C-130H Formation Positioning System (FPS) Engineering and Manufacturing Development (EMD) and Production and Deployment (P&D) support. The purpose of this notice is to provide potential Offerors information regarding the program requirements and to facilitate industry review and maximize the quality of market research. THIS INFORMATION IS FOR PLANNING PURPOSES ONLY AND IS SUBJECT TO CHANGE. The Government encourages questions, comments, and feedback to the documentation attached to this notice. As applicable, this notice will be updated based on continued industry engagement and feedback. This notice does not constitute a formal solicitation, Request for Proposals (RFP), Request for Quotations (RFQ), or a promise to issue a formal solicitation in the future. No contract will be awarded from this notice, and the Government will not reimburse any costs associated with submitting information in response to this posting. Access to Controlled Unclassified Information (CUI) The draft documents associated with this requirement contain Controlled Unclassified Information (CUI). In accordance with DoDI 5200.48, these documents are secured within SAM.gov as "Controlled" attachments to ensure proper safeguarding and access control. Instructions for Requesting Access via SAM.gov: To view the draft C-130 FPS documents, interested parties must perform the following: SAM.gov Account: Ensure you are logged into SAM.gov with an account tied to your organization's valid Unique Entity ID (UEI) and CAGE code. You must have the proper entity administrator roles assigned by your company to request controlled documents. Request Access: Navigate to the "Attachments/Links" section of this notice. Click the "Request Access" button next to the controlled files. Verification: In the request dialogue, please provide your company's CAGE code and a brief statement of interest. Access will be granted to verified US vendors with a legitimate mission-related need to know. Please allow 1-2 business days for the Government to process requests. Special Instructions for System Model Access: Due to file type limitations on the SAM.gov platform, the C-130 FPS System Model document is not available for direct download on this site. How to Request: Interested parties who have successfully been granted access to the 'Controlled' attachments on SAM.gov may request the System Model by emailing the Primary POC (aaron.christy@us.af.mil). Delivery Method: Upon verification of credentials, the Government will transmit the file via DoD SAFE (Secure Analysis and File Exchange). The recipient will receive an automated email from DoD SAFE with a secure link and password to download the file. Feedback Submission: Upon receiving access, vendors are encouraged to submit questions and comments via secure email to the Point of Contact (aaron.christy@us.af.mil). All feedback should be clearly marked with the corresponding document name and section number. Any technical issues regarding SAM.gov document access or DoD SAFE transmittals should be directed to the Primary Government POC

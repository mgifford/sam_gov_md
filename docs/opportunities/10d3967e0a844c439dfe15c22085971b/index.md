# Install New FOC from ITB 910 to ITB 1365

- Agency: DEPT OF DEFENSE
- Type: Presolicitation
- Posted: 2026-05-14 18:21:25.086-04
- Solicitation Number: FA488726R0008

## Summary

This is a Pre-Solicitation Notice. This notice does NOT constitute a request for proposal, request for quote or invitation for bid. A solicitation notice or request for proposal will follow this Pre-Solicitation notice. Department of the Air Force, 56th Contracting Squadron, will solicit for Install New Fiber Optic Cable (FOC) from Information Transfer Building (ITB) 910 to ITB 1365 at Luke Air Force Base, Arizona. The applicable North American Industry Classification System (NAICS) code for this acquisition is 237130 Power and Communication Line and Related Structures Construction with a small business size standard of $45 million. This solicitation will be for a Firm Fixed Price contract which will require the following work, but not limited to engineer, furnish, install and test (EFI&T) 36 Strands (St) Single Mode (SM) fiber optic cable from ITB 910 to ITB 1365, including work in the underground conduit system utilizing maintenance holes, hand holes to install fiber optic cable, fiber optic distribution panel, cable racks, a network switch, UPS and engineer, furnish, install and test the new fiber optic cable system. THIS PROCUREMENT IS AN SBA CERTIFIED WOMEN OWNED SMALL BUSINESS (WOSB) SET ASIDE AND IS LIMITED TO SBA CERTIFIED WOSB. Contractors are required to be certified prior to contract award. NOTE: All contractors will be registered in the System for Award Management (SAM) program in order to receive a contract award from any DOD activity. Contractors may access the Internet site at: sam.gov to register and/or obtain information about the SAM program. No Foreign participation is allowed. The Government anticipates the award of one firm-fixed price contract for this acquisition effort. The successful offeror will be selected using Performance Price Tradeoff (PPT) with Technical Acceptability procedures. Evaluation factors will be set forth in Section M of the solicitation and will include evaluation of the following areas: Technical, Past Performance, and Price. It is anticipated that the solicitation will be issued electronically on or about 29 May 2026 on the Federal Business Opportunities web page at sam.gov. Paper copies will not be made available. The solicitation will be available only through www.SAM.gov, it is incumbent upon the interested parties to visit this website frequently for any updates and/or amendments to all documents. All prospective contractors must be actively registered in the System for Award Management (SAM), in order to be eligible for an award. No other information will be available before the solicitation is posted.

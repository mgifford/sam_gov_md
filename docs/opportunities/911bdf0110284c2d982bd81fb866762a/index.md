# Request for Information_JBSA FSH HVAC Replacement

- Type: Sources Sought
- Posted: 2026-05-11 17:30:48.393-04

## Summary

THIS IS NOT A REQUEST FOR QUOTE: The purpose of this Sources Sought Notice is to query the market for potential interested, capable, responsible, and qualified small businesses that can provide and perform the stated requirement IAW the atatched DRAFT Statement of Work. The Government is interested in collecting market information in accordance with (IAW) RFO Part 10. If interested, please review all attachments and fill out and return a copy of the attached Request For Information (RFI) document along with your capabilities. Please note that this is not a construction requirement. Please return the filled out RFI and capability statement to the POCs in this notice. Description of Services: The contractor shall provide all personnel, equipment, tools, materials, supervision, and quality control necessary for the life-cycle replacement of the HVAC systems at Buildings 590 and 591. The project requires the replacement of the existing systems (SPX ReCold, Model: MW-30C, Serial: MW-10063716-A2) with a "brand name or equal" system. All work will be performed for the 502d Civil Engineer Squadron (502CES) at JBSA-FSH. The objective is to deliver a complete, commissioned, and fully operational HVAC system at each location, in accordance with (IAW) all applicable codes, standards, and manufacturer specifications. Attachments: 1. Request for Information_JBSA FSH HVAC Replacement (fill out) 2. DRAFT SOW - JBSA FSH HVAC Replacement_11May26 3. DRAFT Salient Characteristics - FLUID COOLERS AND PUMPS

# Bridgeport Warehouse Snow Damage Repair and Mitigation

- Agency: AGRICULTURE, DEPARTMENT OF
- Type: Combined Synopsis/Solicitation
- Posted: 2026-04-28 15:20:14.741-04
- Solicitation Number: 1240LT26Q0031

## Summary

Amendment 0001 makes the following change: Due to Presidential Executive Order 14398, FAR Clause 52.222-90 is mandatorily added to all open solicitations to be incorporated into any resulting awards. FAR 52.222-90 is hereby included in the Terms and Conditions. This clause is included as an attachment to the solicitation. No other changes are made. The response date remains the same. THE AMENDMENT MUST BE ACKNOWLEDGED WHEN SUBMITTING YOUR QUOTE. ------------------------------------------------------------------------------------------------------------- Solicitation is updated to include site visit attendance sheet, as well as a single question from the Q&A. See attachments for both documents. ------------------------------------------------------------------------------------------------------------- This is a combined synopsis/solicitation for commercial items prepared in accordance with the format in FAR Part 12. This announcement constitutes the only solicitation. Quotations are being requested an additional written solicitation will not be issued. Solicitation number 1240LT26Q0031 is issued as a Request for Quotation (RFQ) for the construction of a snow canopy aside the Bridgeport Warehouse. Please see attachment 2. SOW for more information. This acquisition is set-aside for small business concerns. The applicable North American Industry Classification Standard Code is 236220 The small business size standard is $45 Million. Thisacquisition is a Total Small Business Set-Aside. All responsible sources may submit a quotation which will be considered by the agency.

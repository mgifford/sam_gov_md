# Portable Dehumidifiers

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-04 19:17:21.315-04
- Solicitation Number: W911S226U3165

## Summary

Salient Characteristics: 22-pint, ENERGY STAR-certified portable dehumidifier with coverage for up to 1,500 square feet. Unit must include an adjustable humidistat and a ?comfort? mode that automatically regulates humidity based on room temperature. The unit shall include soft-touch electronic controls, a water-level window, bucket-full indicator, and capability for continuous drainage using an included hose. Unit must operate down to 41?F, include an ultra-quiet two-speed fan, and use environmentally friendly R32 refrigerant. Delivery Requirement: All items must be delivered no later than 14 days after award.

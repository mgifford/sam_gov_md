# Aerosol Can Crusher

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-04 13:29:22.316-04
- Solicitation Number: W911RQ26QA014

## Summary

Teemark Super 6PJ-VC can and aerosol crusher with 230-volt, single phase, explosion proof motors. Motors are rated at 1.5HP crusher motor and 1 HP blower motor Class 1, Div 1, Grp D. Air driven ejection system which requires 5CFM@80 PSI compressed air. Vapor collection system with 500 CFM blower. 30,000 Lbs. ram force, 20- second cycle time. Includes hydraulic drum Jack. The filtration cabinet is supplied with a manometer to gauge air flow over the filter.

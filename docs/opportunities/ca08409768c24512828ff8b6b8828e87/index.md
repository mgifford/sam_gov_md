## Summary

The objective of this project is to replace the existing water heaters, including demolition of the existing water heaters; installation of a new high-efficiency water heater; reconfiguring the existing water heating system piping; and reconfiguring the existing water heater vent piping along with all electrical work required for related work elements and demonstration/training for BLM site personnel.

# Electronic Security System (ESS) Equipment

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-08 10:46:04.235-04
- Solicitation Number: N4215826QE044

## Summary

This combined Synopsis/Solicitation is for Electronic Security System (ESS) components to support maintenance and installation activities for Norfolk Naval Shipyard (NNSY), Portsmouth, VA. This procurement is for materials only; no installation services are required under this action. This requirement will be procured as a sole?source acquisition from Integrated Security Technologies (IST). The company possesses unique knowledge of the existing ESS infrastructure, including the configuration, architecture, and security posture of the NNSY Automated Access Control System (AACS). Maintaining architectural consistency with the existing AACS is mandatory to ensure system integrity, cybersecurity compliance, and uninterrupted operation of the Shipyard’s access control environment. This solicitation will result in a Firm?Fixed?Price (FFP) award for a Sole?source requirement. No substitutes allowed. Please refer to the attachments for the complete description and specifications. Vendors shall submit: - A completed Solicitation (SF 1449) N4215826QE044 (see attachments) - The Continuation Sheets (8) - A vendor's quote Important Note: Quotes must be all-inclusive, including shipping and any other associated costs. No additional charges will be accepted after award.

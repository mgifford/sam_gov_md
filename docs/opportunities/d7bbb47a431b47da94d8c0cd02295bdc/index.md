# 42 OSS - Fire Bottles for Flightline Operations

- Agency: DEPT OF DEFENSE
- Type: Sources Sought
- Posted: 2026-05-26 16:24:26.76-04
- Solicitation Number: FA3300OSS26I

## Summary

The 42nd Contracting Squadron, Maxwell AFB, AL, requests information from industry to procure ten new Amerex Model 775, 150?lb wheeled, stored?pressure fire extinguishers charged with Novec 1230 or SF1230, or an approved equivalent, for flightline use by the 42nd Air Base Wing, 42nd Operations Support Squadron (42 OSS). This requirement includes unique characteristics necessary for compatibility with the end user’s existing equipment inventory. Information gathered from this notice will be used to finalize the acquisition strategy for the requirement described in the attached Draft Statement of Requirements (SOR).

# GelSight Software Purchase

- Agency: DEPT OF DEFENSE
- Type: Special Notice
- Posted: 2026-05-22 14:00:43.052-04
- Solicitation Number: PANRSA-26-P-0000036839

## Summary

THIS IS A SOLE SOURCE SYNOPSIS. ACC-RSA has a Sole Source Requirement for GelSight Software Purchase. This is a Sole Source with Keysight, IAW FAR 16.505(b)(2)(i)(B). IAW FAR 16.505(b)(2)(i)(B), GelSight, Inc is the only source capable of fulfilling the Government's requirement for GelSight Modulus™ and GelSight Mobile™ Series 2 Systems. The GelSight system utilizes proprietary and patented elastomeric sensor technology that provides unique and essential capabilities for our mission. No Solicitation documents exist at this time. This item utilizes North American Industry Classification System (NAICS) Code of 513210. IAW FAR 5.207(c)(16_(ii) all responsible sources may submit a capability statement, proposal, or quotation, which shall be considered by the agency. ACC-RSA will not be responsible for any costs incurred by the interested parties in responding to this notice. This notice of intent is not a request for competitive quotes. Phone calls will not be accepted.

# JBER 3D Diorama

- Agency: DEPT OF DEFENSE
- Type: Combined Synopsis/Solicitation
- Posted: 2026-05-06 18:45:12.238-04

## Summary

Design, fabrication, and delivery of one (1) custom 3D topographical base map diorama of Joint Base Elmendorf-Richardson (JBER), Alaska. The requirement includes a 4-quadrant modular design incorporating specific man-made and landscape features detailed in the Salient Characteristics.
